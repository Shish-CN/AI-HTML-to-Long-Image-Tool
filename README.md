# AI HTML 转长图工具
## AI HTML to Long Image Tool

专为 AI 对话生成的 HTML 内容打造，一键粘贴、实时预览、导出完整高清长图，让阅读与传播更简单。
Built specifically for HTML content generated by AI chatbots. One-click paste, real-time preview, and full HD long image export for easier reading and sharing.

---

## 核心功能 | Features
- 📝 **粘贴 AI 生成的 HTML 代码**
  直接粘贴你与 AI 对话后生成的文章、总结、排版页面
  Paste HTML articles & summaries generated from AI chats

- 👁 **实时渲染预览**
  即时查看 AI 生成的排版效果，无需本地打开
  Instantly preview AI-generated layout without opening new tabs

- 🖼️ **一键导出完整长截图（超长内容支持）**
  自动捕获完整页面，生成 1080px 宽高清长图
  One-click export full-page long screenshot with 1080px width

- 🚀 **无后台、纯前端**
  代码不上传、不泄露，保护你的 AI 对话内容
  No backend, no data upload, protects your AI chat content

- 🗑 **一键清空，快速复用**
  清空代码与预览，继续生成下一篇内容
  One-click clear for quick reuse

---

## 适用场景 | Use Cases
- 与 AI 聊天后生成的文章、总结、报告转图片
  HTML articles & summaries from AI chats → image
- 公众号、朋友圈、小红书、社群快速传播
  Quick sharing to social platforms
- 长文阅读不便，转为长图更清爽
  Convert long content to clean long images
- 保存 AI 生成的排版内容，便于存档
  Archive AI-generated formatted content

---

## 使用方式 | How to Use
1. 让 AI 生成文章/总结的 HTML 代码并复制
   Generate & copy HTML from AI chat
2. 打开工具，粘贴到代码框
   Open tool and paste HTML
3. 点击「实时预览」查看效果
   Click "Preview"
4. 点击「导出完整长图」自动下载
   Click "Export Image" to download
5. 直接分享或保存
   Share or save the image

---

## 部署 | Deployment
- 本地：直接打开 `index.html` 使用
  Local: open `index.html` in browser
- 线上：部署到 Vercel，随时随地使用
  Deploy to Vercel for online access anytime

## 技术栈 | Tech Stack
- HTML / JavaScript / TailwindCSS
- html2canvas 长截图
- 纯前端，无服务端
